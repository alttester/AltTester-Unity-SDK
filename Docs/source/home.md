# AltTester® Unity SDK

AltTester® Unity SDK instruments a Unity game so you can find its objects and interact with them
from tests written in C#, Python, Java or Robot Framework — on a device, or in the Editor.

**New here?** Read **How it works** first, then
**Requirements** and follow Get started through to your first
passing test.
